# Tracker digest — 2026-05

*Compiled 2026-05-14. Reflects the state of the table at repo launch.*

## What moved this month

The initial sweep, since this is the first digest. Highlights:

- **AIME 2024 / 2025**: frontier reasoners (closed and open) cluster in the 85-95% pass@1 range. The benchmark is now a discriminator only at the very top, and is approaching saturation for distinguishing top closed from top open.
- **MATH-500**: saturated at the top tier. Most credible frontier models report mid-to-high 90s. We list it on the tracker as historical reference; new releases should now anchor on AIME / FrontierMath.
- **FrontierMath**: still a meaningful discriminator. Top closed reasoners reportedly post low-teens percentages on full FrontierMath; the rest of the field is in single digits. Numbers move quietly; check Epoch AI announcements.
- **SWE-bench Verified**: agent-mode reasoning systems continue to climb. The 2025 numbers cluster in the 70-80% range for top closed agents; methodology (multi-attempt vs single, tool use) varies considerably between reports and is not always disclosed.
- **ARC-AGI-3**: launched 2026-03-25. SOTA still unstable; expect substantial movement over the next 90 days as the leaderboard fills.
- **Codeforces Elo**: vendor-reported numbers north of 2700 from OpenAI's o-class models. No public account, no independent verification — treat as illustrative.

## Methodological notes from this sweep

Several recurring issues we encountered while compiling the table:

1. **Inconsistent pass@k disclosure**. Some headline numbers labeled "pass@1" silently use majority-vote-over-k or best-of-N. When in doubt, we follow the convention of the model card; we note the ambiguity in the cell.

2. **Different AIME slices**. Some reports include AIME I + AIME II of a given year, some report only AIME I, some report a single problem set. We use combined-set numbers where available.

3. **Tool use ambiguity on SWE-bench**. "SWE-bench Verified" can mean (a) the model produces a patch alone, (b) the model uses repository search / shell tools to navigate first. We try to flag this, but reports are not always clear.

4. **Contamination concerns**. AIME and Codeforces problems frequently appear in training corpora. Numbers should be interpreted relative to contamination-controlled comparisons where available (e.g. LiveCodeBench's date-cutoff design).

## What to watch over the next 90 days

- ARC-AGI-3 leaderboard maturity. Expect first stable SOTA by August 2026.
- Open-model reproductions of next-generation closed reasoners. The R1 → o1 catch-up was ~ 3 months in 2025; analogous catch-up cycles are likely.
- FrontierMath quarterly evaluations from Epoch AI.
- HLE drift: as expert evaluators add new problems, the benchmark's hardness moves; track the version.
